# AI 批量翻译工具 使用说明

一个 Windows 桌面小工具：**调用 AI 接口批量翻译 txt、json、md、csv、srt、log、text 文件**，
纯 Python 标准库实现（tkinter），无需安装任何第三方包。

> 只需电脑装有 Python 3（已安装 3.12）。双击 `启动翻译工具.bat` 即可打开程序。

---

## 一、快速开始

1. 双击 **`启动翻译工具.bat`**（或在命令行执行 `python main.py`）。
2. 点击 **“＋ 添加文件夹”**（或“添加文件”），勾选“包含子文件夹”可递归处理。
3. 确认 **输出目录**（默认生成在源目录下的 `翻译结果` 文件夹，不会覆盖原文件）。
4. 选择 **源语言 → 目标语言**，点击 **“▶ 开始翻译”**。
5. 翻译过程中**进度条会按 AI 请求批次实时推进**，完成后点 **“打开输出目录”** 查看结果。

> 首次使用请先点 **【设置…】** 填写 Base URL / API Key / 模型，并用“测试连接”验证。

## 一之二、对话翻译（左右双面板，随手翻译一句话/一段话）

主界面底部点 **“💬 对话翻译”** 打开翻译面板（类 Google 翻译布局，不读写文件，纯手动输入）：

- 顶部两个下拉框选 **源语言 / 目标语言**（默认沿用主界面设置，可任意组合如 英→韩、日→越），中间 **↔** 按钮一键对调语言；
- **左侧输入、右侧译文**：输入用大字号编辑框，译文以蓝色大字显示；
- **写好内容后点左侧“▶ 翻译”按钮才翻译**（也可按 **Ctrl+Enter**）；**输入过程中不会自动翻译**，不会偷偷消耗额度；
- 语言/风格改变后旧译文会被清空，点一次“▶ 翻译”即可按新设置重译；
- 左侧下方是**示例短语**（按源语言变化，如 Hello / How are you? / Thank you），点一下只**填入输入框**，仍需点“▶ 翻译”；
- 右侧下方 **风格** 下拉：`默认 / 非正式 / 正式`（控制译文语气）；
- 两侧都有 **⧉ 复制** 与 **🔊 朗读**：朗读用 Windows 自带语音，**再点一次同一侧可停止朗读**；
  **关闭这个窗口或退出程序时，后台朗读会立即停止**（不会出现"关掉软件还在读"）；
- 左下 **“✕ 清空”** 一次清空输入与译文；底部显示当前使用的接口预设，可点 **“设置…”** 随时切换。

## 二、AI 接口设置（OpenAI 兼容）

打开 **【设置】**，最上面是 **“接口预设”**，可保存多组账号/接口一键切换：

- 每组预设包含：名称 + Base URL + API Key + 模型；
- 点 **“＋ 新建预设…”** 把当前输入保存为新预设（如 DeepSeek、OpenAI、通义各建一组）；
- 下拉选择预设即 **一键切换** 该组的 API Key 与模型；
- 改完输入后点 **“保存到当前预设”** 覆盖保存；切换前若有未保存修改会询问是否先保存；
- **“删除预设”** 可删除多余组（至少保留一组）；点“保存并关闭”同样生效。

Base URL 常见示例（新建预设时可直接填入）：

- DeepSeek：`https://api.deepseek.com/v1`
- OpenAI：`https://api.openai.com/v1`
- 通义千问（DashScope 兼容模式）：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 智谱 GLM：`https://open.bigmodel.cn/api/paas/v4`
- Moonshot Kimi：`https://api.moonshot.cn/v1`

API Key 在对应平台官网申请，形如 `sk-...`；模型如 `deepseek-chat`、`gpt-4o-mini`、`glm-4-flash`、`moonshot-v1-8k` 等。
填好后点 **“测试连接”**，看到绿色“测试成功”即可使用。

> 所有预设的 API Key 都保存在程序目录的 `config.json` 里（明文，仅本机使用）。请勿分享该文件。

## 三、翻译语言选择（左右两个下拉框）

主界面“③ AI 翻译设置”里是 **“源语言 → 目标语言”两个下拉框**，可自由组合：

- **源语言**：`自动识别` + 英语 / 中文 / 日语 / 韩语 / 法语 / 德语 / 俄语 / 西班牙语 / 意大利语 / 葡萄牙语 / 泰语 / 越南语 / 阿拉伯语 / 印地语 / 希腊语 / 荷兰语 / 波兰语 / 土耳其语
- **目标语言**：同上（不含“自动识别”）

用法举例：**英 → 韩**（把英文翻成韩语）、**日 → 越**（日语翻成越南语）、**中 → 日**、**自动识别 → 英**（自动判断文件里各段是什么语言并翻成英语）等。

说明：
- “自动识别”按文字体系判断（假名=日文、谚文=韩文、西里尔=俄文…）；
- 已经是目标语言的内容不会被重复翻译（例如 英→韩 时，韩文内容原样保留）；
- 英/法/德等拉丁字母语言文字体系相同、无法靠字形区分，选择哪一种就按哪种语义翻译即可；
- 源语言与目标语言选成相同（如 英→英）时，点开始会给出提示，不会空转。

## 四、格式处理规则

| 格式 | 处理方式 |
| --- | --- |
| `.txt / .md / .log / .text` | 按行翻译，段落空行保留 |
| `.json` | **保留结构与键名**（可选“键名也翻译”），只翻译字符串值；自动跳过 URL、路径、数字、版本号、日期、UUID、代码标识符等 |
| `.srt` | 保留序号与时间轴，只翻译字幕文本 |
| `.csv` | 保留表头与行列结构，只翻译数据单元格；自动识别 `,` `;` `\t` 分隔符 |

- 输入编码自动识别（UTF-8 / UTF-16 / GBK 等）；输出编码可在【设置】选择
  （UTF-8 / UTF-8 含 BOM / GBK）。**用 Excel 打开 CSV 出现乱码时请选“UTF-8（含 BOM）”**。
- 相同文本会自动去重，只调一次 AI，加快速度、节省额度；同一批文件之间也共享缓存。
- AI 调用自动分批、失败自动重试，个别段落标记异常时会退回逐段翻译，保证结果完整。

## 五、进度与状态

- 顶部绿色进度条：以“文件”为整格、每完成一批 AI 请求推进一格内的进度，翻译大文件也能看到实时变化；
- 文件列表右侧状态列：`翻译中… → ✓ 完成 / ✗ 失败`；
- 底部日志：显示每个文件翻译了多少单元、发起了多少次请求、总用时。

## 六、常见问题

1. **点“开始翻译”提示未配置**：先到【设置】填写 Base URL / API Key / 模型（三项都要填）。
2. **测试连接报 401 / 403**：API Key 无效或额度不足；**404**：Base URL 写错（应以 `/v1` 结尾）；**429**：请求过频或余额不足。
3. **翻译一半想停**：点“■ 停止”，当前批次结束后停止。
4. **想改翻译结果位置**：手动在“输出目录”输入框填任意路径，或用“浏览…”选择。
5. **语言没有翻对？** 检查“源语言/目标语言”两个下拉框是否选对；拉丁字母语言（英法德等）字形无法区分，可换“自动识别”或对号选择。

## 七、目录结构

```
翻译工具/
├─ main.py                入口
├─ app.py                 tkinter 图形界面（批量翻译 + 进度条 + 多预设设置）
├─ chat_window.py         对话翻译面板（输入文本 → AI 即时翻译）
├─ config.py              设置读写（config.json）
├─ langs.py               多语言支持：文字识别 / 语言下拉
├─ ai_client.py           OpenAI 兼容 AI 客户端
├─ engine.py              翻译引擎（txt/json/csv/srt 管线 + 分批进度）
├─ 启动翻译工具.bat         双击启动
├─ 示例/                  sample.txt、sample.json（可先拿它们试跑）
└─ README使用说明.md
```
